# Антикварный салон «Retro Room»

Интернет-магазин для антикварного салона с каталогом, корзиной, избранным, авторизацией и историей заказов.

## Демо

**Статическая версия:**  
https://elina07.gitverse.site/antique-salon/ 

*PHP-функционал (оформление и отправка заказа, история заказов) требует локального сервера с поддержкой MySQL. Статическая версия демонстрирует вёрстку, каталог, корзину и избранное.*

## Функционал

### Работает везде (включая статическую демку)
- Каталог товаров с фильтрацией по категориям, цене, периоду
- Сортировка товаров
- Постраничная навигация
- Корзина (добавление/удаление, сохранение в localStorage)
- Избранное
- Блог с поиском
- Форма обратной связи
- Адаптивный дизайн (ПК, планшет, телефон)
- Бургер-меню на мобильных устройствах

### Требуют PHP + MySQL (локальный сервер)
- Оформление и отправка заказа
- История заказов

## Стек технологий

- **HTML5** — семантическая разметка страниц
- **CSS3** — адаптивная вёрстка, Flexbox, Grid, анимации, кастомные свойства
- **JavaScript (ES6+)** — корзина, избранное, фильтрация, модальные окна, поиск по блогу, работа с `localStorage`
- **PHP 7.4** — обработка заказов, работа с базой данных (серверная логика)
- **MySQL** — хранение заказов
- **Bootstrap 5** — адаптивная сетка и компоненты
- **Git** — контроль версий и хостинг кода

## Как открыть

### Статическая версия (без PHP)

1. Скачайте репозиторий
2. Откройте файл `index.html` в браузере
или демо версия: https://elina07.gitverse.site/antique-salon/

### Полная версия (с PHP и MySQL)

1. Установите локальный сервер: **OpenServer**, **XAMPP**
2. Скопируйте папку проекта в `htdocs` (или `domains`)
3. Импортируйте базу данных:
   - Откройте **phpMyAdmin** (`http://localhost/phpmyadmin`)
   - Создайте новую базу данных, `antique_shop`
   - Перейдите во вкладку **Импорт**, выберите файл `antique_shop.sql` и нажмите **Вперед**
4. Запустите сервер и откройте `http://localhost/antique-salon`

#### Пример настройки подключения к БД (файлы `php/order.php` и `php/get_orders.php`):

```php
$host = 'localhost';
$db   = 'antique_shop';
$user = 'root';
$pass = '';
```
